# 任务: 12种Agent故障模式小手册

你是本项目的写作执行者。在当前工作目录下完成以下工作:

1. 创建 `work/chapters/` 目录结构(用文件工具直接写文件即可)。
2. 依次撰写 12 个章节文件: `work/chapters/ch01.md` 到 `work/chapters/ch12.md`,
   主题分别为12种长流程agent任务的常见故障模式, 每章至少120字中文, 内容需具体、有操作建议:
   - ch01 API限流(429) ch02 上游5xx与网关错误 ch03 流式响应中断
   - ch04 配额/余额耗尽 ch05 认证与key失效 ch06 上下文超长污染
   - ch07 工具调用死循环 ch08 幻觉式"提前宣布完成" ch09 依赖服务超时
   - ch10 进程僵死与心跳丢失 ch11 文件系统冲突与半成品写入 ch12 无人值守的安全边界
3. 在 `work/PROGRESS.md` 维护一张12项 checklist(`- [x]`/`- [ ]`),
   每写完一章立即把对应项打勾。该文件是断点续传的唯一进度依据。
4. 全部12章完成后停止, 不需要写总结报告。

写作风格: 面向运维者, 直接给"症状/处置/预防"三段式。
