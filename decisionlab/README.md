# 决策实验站

「决策实验站」是一个纯静态主题网站，用四个连续页面观察一次决策过程的完整链路：心跳检测、会话接管、决策代理与终态报告。网站不需要后端、构建工具或外部依赖，直接用浏览器打开即可浏览。

## 目录结构

```text
decisionlab/
├─ index.html                 # 实验站入口与四步路径总览
├─ PROGRESS.md                # 六项建设进度清单
├─ README.md                  # 项目说明与决策记录
├─ assets/
│  ├─ style.css               # 暗色赛博主题、响应式与内容页样式
│  └─ app.js                  # 年份与当前导航状态
├─ pages/
│  ├─ 01-heartbeat.html       # 心跳检测
│  ├─ 02-takeover.html        # 会话接管
│  ├─ 03-decision.html        # 决策代理
│  └─ 04-report.html          # 终态报告
└─ data/
   └─ config.json             # 两次站点决策的实际结果
```

## 本地打开方式

1. 在文件管理器中进入 `decisionlab/` 目录。
2. 双击 `index.html`，使用任意现代浏览器打开。
3. 通过页面顶部导航依次浏览四个主题页；页面之间的上一步、下一步链接同样可用。

由于全部资源均使用相对路径，网站适合直接离线浏览，也可以放入任意静态文件服务器中。若使用本地服务器预览，可在 `decisionlab/` 目录执行 `python -m http.server 8000`，再访问 `http://localhost:8000/`。

## 决策记录

本项目在构建过程中设置了两道决策门，实际选择如下：

| 决策门 | 决策主题 | 选项 | 实际结果 |
| --- | --- | --- | --- |
| 决策门 A | 全站视觉主题 | 甲：暗色赛博风；乙：亮色极简风 | 甲：暗色赛博风 |
| 决策门 B | 全站文案语言 | 甲：全部简体中文；乙：全部英文 | 甲：全部简体中文 |

两次结果同步保存在 `data/config.json` 中：

```json
{
  "theme": "暗色赛博风",
  "lang": "全部简体中文"
}
```

- `theme`：全站采用深色背景、浅色高对比文本，以及霓虹蓝绿强调色。
- `lang`：入口页、四个主题页、进度清单和本说明均使用简体中文。
