06 / EGRESS PROXY

出站代理

让所有 Agent 出站请求经过统一网关，在白名单、数据分级、速率限制和审计记录的共同约束下访问外部世界。

安全层策略：默认拒绝今日拦截：17 次当前状态：正常

机制目标

出站代理把分散在每个工具中的访问控制收敛到一个可审计入口。Agent 不直接持有网络出口，只声明目标、用途和数据级别，由代理依据会话授权决定放行、改写或拒绝。

策略执行

  • 默认拒绝未登记域名、未知协议和裸 IP 请求。
  • 按会话角色限定可访问域名、方法与速率预算。
  • 对请求体和响应体进行敏感数据扫描，阻止意外外传。
  • 高风险目标需要一次性授权，并要求说明业务用途。

审计记录

每次出站都记录会话标识、目标、方法、策略结论、数据等级与请求摘要。敏感内容不以明文落库，价值在于还原“谁在何时尝试发送什么到何处”。

失败处理

策略拒绝不会自动重试；网络失败只在白名单目标内退避；代理不可用时默认阻断出站，而不是绕过代理直连。这一失败关闭原则保护边界不被临时故障侵蚀。

核心原则

默认拒绝、最小授权、全程审计；代理不可用时宁可停止，也不能绕行。
