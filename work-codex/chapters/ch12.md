# 第12章 无人值守的授权边界

## 要点

无人值守不等于无限授权。系统必须把权限拆成可执行动作、资源范围、金额或调用量、有效时间和环境四要素，并默认最小权限。删除、覆盖、发布、付款、发送外部消息、修改权限和访问敏感数据等高风险动作需要预先授权的凭证或人工闸门；策略由平台强制执行，不能只写在提示词里依赖 agent 自觉。

## 做法

使用短期凭据、作用域令牌和分环境账户，所有高风险工具经过策略引擎并绑定任务 ID；授权清单在启动前冻结并展示，越界请求立即拒绝、告警并保存上下文。设置总成本、速率、文件路径、域名和外部接收方的硬限制，达到阈值先安全暂停。紧急停止应能撤销凭据、停止派生任务并保全现场；恢复运行需要新的、有期限的授权。

## 反例

给 agent 一个永久管理员密钥并相信它会谨慎操作，一旦提示注入或模型误判就会造成全局破坏；允许自动 push、发信和删除缓存却不设白名单，会使错误难以撤回；把“继续直到完成”解释为可以自行扩权，更是把任务坚持变成了安全事故。
