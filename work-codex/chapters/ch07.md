# 第07章 验收清单与机器可验证的完成判据

## 要点

“完成”必须由独立于执行 agent 的验收器判定。清单中的每一项都应关联对象、条件、验证命令或接口、期望结果和证据位置，例如文件存在且可解析、测试退出码为零、产物哈希匹配、远端记录可查询。自然语言描述只能作为说明，不能作为最终判据；主观质量项也要拆成评分规则、抽样范围与人工复核门槛。

## 做法

为任务定义不可变验收版本，执行前冻结，变更时显式升级。验收器读取原始需求和产物，而不能只读 agent 自报摘要；能自动验证的项全部自动化，失败项输出事实、证据与最小复现。状态机只在所有硬性判据通过后进入 SUCCEEDED，允许带明确残留风险的 PARTIAL，并区分环境失败、产品失败与验收器自身异常。

## 反例

看到日志里写着“全部完成”就结束，会放过空文件、漏章节和未推送提交；让执行 agent 自己运行并解释自己的测试，容易共享同一错误假设；只检查文件数量而不检查内容与结构，则十二个占位符也能骗过监管器。
